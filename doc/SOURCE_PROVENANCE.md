# 源码与许可证来源

维护者为本项目有权授予的原创贡献选择 Apache-2.0；根 LICENSE 为标准全文，NOTICE 记录项目声明。该选择允许依许可证商业使用、修改和分发，不自动授予第三方代码、品牌或素材的权利。

项目基于公开的 HTTP、数据模型和行为契约实现原型与系统管理功能，通过 Maven 依赖复用 hsweb、EasyORM、Spring、Reactor、Jackson、Apache Commons 等组件。当前生产依赖未引入 JetLinks 商业模块；这不等于对所有参考实现及贡献权属作出法律认证。

维护者应确认实际提交内容的贡献者/雇主授权、参考或迁移实现的再分发范围，并记录必要的第三方声明。源文件哈希或未发现逐字节重复，都不能证明完全不存在派生内容。无明确分发权的内容应取得授权或替换，不能仅靠改名、重写声明或增加 LICENSE 解决。

Maven Wrapper 保留其原有许可头。第三方组件按实际版本及文件的许可处理；普通 JAR 随附项目 LICENSE/NOTICE，正式 release-audit 会生成并打包第三方清单、完整许可文本与适用声明，详见 [公开发布指南](public/RELEASE.md)。

历史内部审计证据不属于默认公开源码文件集。当前未提供远端 CI 工作流；README 和公共开发指南列出可实际执行的手动门禁。源码导出不发布代码、不修改凭据、不包含 Git 历史，也不代替权属与生产验收。
